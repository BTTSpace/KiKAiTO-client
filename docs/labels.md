# Label meanings

All readers use the same English label names.

| Label | Meaning |
| --- | --- |
| `needs-customer-response` | A customer reply is required. |
| `needs-customer-decision` | Choose an option about a feature; a recommendation is included. |
| `awaiting-demo` | A demo or screenshots are not available yet. |
| `in-progress` | The feature is being built or adjusted. |
| `awaiting-acceptance` | A shown version is ready for customer acceptance. |
| `updated-review` | Feature content has changed; read the linked update. |
| `bilingual` | English and Chinese explanations are available. |
| `scope-change` | A feature is added to the original plan. |
| `FR-2026-10-12-01` | Connects issues to the preserved homepage feedback document. |
| `CR-2026-10-12-01` | Permanent update record 01 registered on 2026-10-12. |
| `CR-2026-10-12-02` | Permanent update record 02 registered on 2026-10-12. |
| `CR-2026-10-12-03` | Permanent update record 03 registered on 2026-10-12. |
| `CR-2026-10-12-04` | Permanent update record 04 registered on 2026-10-12. |
| `bug` | Something behaves incorrectly. |
| `enhancement` | A feature addition or improvement. |
| `question` | A question about the website. |
| `accessibility` | A difficulty using the website with an accessibility need. |
| `documentation` | A change to written explanations. |
| `duplicate` | The same request is already recorded elsewhere. |
| `invalid` | The report does not describe an applicable website issue. |
| `wontfix` | The request will not be implemented. |
| `help wanted` | Additional assistance is requested. |
| `good first issue` | A small task suitable for a new contributor. |

Only issues with `needs-customer-response` require a reply now. A source or update label does not require a reply by itself.

# 標籤說明

所有讀者使用相同英文標籤名稱。

| 標籤 | 意義 |
| --- | --- |
| `needs-customer-response` | 需要客戶回覆。 |
| `needs-customer-decision` | 需選擇功能選項，題目附建議選擇。 |
| `awaiting-demo` | 尚待提供 demo 或截圖。 |
| `in-progress` | 功能正在製作或調整。 |
| `awaiting-acceptance` | 已有展示版本，待客戶驗收。 |
| `updated-review` | 功能說明有變動，請看更新。 |
| `bilingual` | 有英文及中文說明。 |
| `scope-change` | 相對原計劃新增功能。 |
| `FR-2026-10-12-01` | 對應已保存的首頁回饋原件。 |
| `CR-2026-10-12-01` | 2026-10-12 登錄的第 01 次永久更新紀錄。 |
| `CR-2026-10-12-02` | 2026-10-12 登錄的第 02 次永久更新紀錄。 |
| `CR-2026-10-12-03` | 2026-10-12 登錄的第 03 次永久更新紀錄。 |
| `CR-2026-10-12-04` | 2026-10-12 登錄的第 04 次永久更新紀錄。 |
| `bug` | 功能行為有錯。 |
| `enhancement` | 新增或改善功能。 |
| `question` | 關於網站的問題。 |
| `accessibility` | 網站使用上的無障礙問題。 |
| `documentation` | 說明文件的修改。 |
| `duplicate` | 其他議題已記錄相同需求。 |
| `invalid` | 回報內容不適用於此網站議題。 |
| `wontfix` | 不安排實作的需求。 |
| `help wanted` | 需要其他協助。 |
| `good first issue` | 適合新參與者的小任務。 |

只有 `needs-customer-response` 表示現在需要回覆，來源單號或更新標籤本身不要求回覆。
