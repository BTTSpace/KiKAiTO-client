The existing system is bilingual; this work revamps the English version and preserves Chinese behavior. Every issue shows complete English with expandable Chinese below. Qualified screenshots must match the original website design; missing evidence remains pending.

Reply in either language on the relevant feature issue. Without a GitHub account, use your usual contact channel and provide the feature name or link; the owner records the respondent, date and reply. This repository is public, so private materials use the usual private channel.

Permanent source and batch labels support historical lookup. `updated-review` is temporary, `bilingual` identifies language availability, and `scope-change` identifies added scope awaiting agreement. Customer silence is not approval. The owner records demonstrated version/date, check results and customer confirmation before closing feature issues.

Source code and detailed check logs remain private. Repository visibility is a separate decision.
