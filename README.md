# KiKAiTO English website revamp

View [all features and progress](https://github.com/BTTSpace/KiKAiTO-client/issues/2) or [questions for you](https://github.com/BTTSpace/KiKAiTO-client/issues/3). The English website is being revamped; the existing Chinese pages remain available.

- [Label meanings](docs/labels.md)
- [How to read and reply](https://github.com/BTTSpace/KiKAiTO-client/issues/1)
- [Homepage feedback FR-2026-10-12-01](https://github.com/BTTSpace/KiKAiTO-client/issues/18)
- [Received documents](docs/customer-feedback/README.md)
- [Feature scope](docs/scope-v2.md)

Each issue shows English first, with Chinese below. Reply in either language, in an issue comment or via LINE with the issue number.

- `needs-customer-response`: a reply is required.
- `needs-customer-decision`: each question has a recommendation and a reason. If no change is needed, we proceed with that recommendation. For a change, select another option or “Other” and describe your proposal; comment or reply via LINE.

After each feature is implemented, we provide screenshots; for motion or interactive features, also provide a demonstration video or an interactive demo. When the demo link is provided, review the shown version and tell us what should change or confirm that it meets the acceptance list. This is the feature-planning stage; those demonstrations follow implementation.

This repository is public. Send private materials through LINE.

# KiKAiTO 英文網站改版

查看[全部功能與進度](https://github.com/BTTSpace/KiKAiTO-client/issues/2)或[請你回答的問題](https://github.com/BTTSpace/KiKAiTO-client/issues/3)。本次改版英文網站，既有中文頁面仍可使用。

- [標籤說明](docs/labels.md)
- [操作與回覆指南](https://github.com/BTTSpace/KiKAiTO-client/issues/1)
- [首頁回饋 FR-2026-10-12-01](https://github.com/BTTSpace/KiKAiTO-client/issues/18)
- [收到的文件](docs/customer-feedback/README.md)

議題先顯示英文，中文在下方展開；可用任一語言在議題留言或透過 LINE 註明議題編號回覆。

- `needs-customer-response`：需要回覆。
- `needs-customer-decision`：每題附建議方案及理由，無需調整就依建議執行；需調整時可選其他選項，或選「其他」填寫自己的建議，在議題留言或透過 LINE 回覆。

各功能完成實作後提供畫面截圖；動態或互動功能另附展示影片或可操作 demo。提供 demo 連結後，核對展示版本，提出需修改之處，或確認符合驗收條件。目前為功能規劃階段，展示於功能完成後提供。

本倉庫公開，私密素材使用LINE交付。
